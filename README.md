# Minor Hobby Projects Portfolio
Collection of some of my small hobby projects. Their scope is too little for a separate repository, but they still stand as a sincere tribute to my lifetime passion for creation.

Each of the projects is contained within it's own subfolder.

## Overview of the projects.

### RC Car Powertrain
In the [RC_Car_Powertrain/](./RC_Car_Powertrain/) folder you can see a drive system for an RC car. It consists of a custom 3D printed frame, two brushless motors, metal shafts, a differential, shock absorbers, custom wheel hubs. It took a lot of prototyping to get the parts work together neatly.

I abandoned the project when I started the University, as I picked up other tasks.
